# 对于abc443D的思考——差分约束
#### A. “左右扫描”模型（必须掌握）
这道题是这类模型的教科书级例题。以后只要看到：
1.  **线性数组**（一排房子、一排山峰、一排数字）。
2.  限制条件是 **相邻两项的关系**（例如 $|a_i - a_{i+1}| \le k$，或者 $a_i > a_{i-1}$）。
3.  求最大值/最小值/总和。

**立刻形成条件反射：**
- **拆分限制**：把 $|x - y| \le 1$ 拆成 $x \le y+1$ 和 $y \le x+1$。
- **方向性**：$x \le y+1$ 是 $y$ 限制 $x$（从右往左传），$y \le x+1$ 是 $x$ 限制 $y$（从左往右传）。
- **解法**：正着扫一遍满足左边限制，反着扫一遍满足右边限制，最后取 `min`（如果是求最小代价）或 `max`。

**也就是对于小于等于或者大于等于这种类型的，就可以考虑一下上限或者下限。有绝对值的往往拆开，分为前后的情况**

#### B. 提升对“差分约束”的敏感度
这道题本质上是 **差分约束系统（Difference Constraints）** 的简化版。
- 一般的差分约束需要建图跑最短路（SPFA/Dijkstra）。
- 但因为本题是线性的（只和左右邻居有关），所以可以直接 DP（也就是两次扫描）。
- **训练点**：当你看到 $x_i - x_j \le c$ 这种不等式时，要意识到这是在限制上界。

#### C. 改变“构造”题的思考方式
你之前的思路是“怎么摆放棋子（动作）”。
高阶选手的思路通常是 **“最终状态必须满足什么性质（状态）”**。
- **你的思路**：我先找个最低点，然后在这个基础上把旁边的拉高……（过程导向，容易漏情况）
- **推荐思路**：每个位置 $i$ 的高度 $H_i$ **最多**能是多少？它受限于 $R_i$，也受限于 $H_{i-1}+1$，也受限于 $H_{i+1}+1$。所有限制取交集（min），就是答案。（结果导向，数学证明）
